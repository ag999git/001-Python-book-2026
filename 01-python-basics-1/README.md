
# Chapter 1: Python Basics

The online companion to Chapter 1 of the book. The printed chapter introduces comments, identifiers, keywords and PEP 8. These pages add the two things a printed page cannot give you: room to explain an idea at length, and step-by-step help with setting up the tools you will write your code in.

By the end of these pages you should have a working Python setup on your own computer, know how to run code in three different places, and be comfortable with the naming and layout rules that Python programmers follow.

Nothing here assumes any previous programming experience.

## Suggested Reading Order

1. **Python Basics** for the ideas in the printed chapter.
2. **One** of Jupyter Notebook, VS Code or Google Colab, whichever suits your machine. You do not need all three.
3. **VS Code Part 2** if you chose VS Code and want notebooks inside it.
4. **Questions and Answers** and **Exercise Questions** when you revise.
5. **Interning** only once the rest is comfortable. It explains a surprise rather than teaching a skill.

## Using the Code

Every script on these pages is complete and ready to run. Copy it into a `.py` file, or paste it into a notebook cell. Where a script produces output, that output is shown underneath it, so you can check your result against the book's.
