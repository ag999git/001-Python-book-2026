
# Google Colab Notebooks

Every script printed in the book is already typed out for you here. Open a notebook,
press **Run**, and watch the code work — then change it and run it again. Nothing to
install: Colab runs Python in your browser, on any computer.

Each notebook mixes two kinds of cell. **Text cells** explain what is happening;
**code cells** hold the scripts from the printed chapter. Run the code cells in order
the first time through, because later cells often use variables created by earlier ones.

> **Tip:** your changes are not saved back here. To keep your own version, use
> **File → Save a copy in Drive** in Colab. Your copy is yours to experiment with.

## Opening a notebook without these links

Any notebook on GitHub can be opened in Colab by hand. Take its GitHub address and
replace `github.com/` with `colab.research.google.com/github/`:

```
https://github.com/ag999git/001-Python-book-2026/blob/main/colab-nb/11-10-numpy.ipynb
https://colab.research.google.com/github/ag999git/001-Python-book-2026/blob/main/colab-nb/11-10-numpy.ipynb
```

Chapter 1 has a full walkthrough of Colab — see *Getting Started with Google Colab*.
